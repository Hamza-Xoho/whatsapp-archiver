## Controller rulings
1. `store.OpenReadOnly(path) (*Store, error)`: fails with a clear error if the file does not exist (`no archive at <path>: run archiver first`), opens with `mode=ro` (and `immutable` NOT set — the service may be writing; WAL readers are fine), no migrations, no pragmas that write, no write pool (write methods on such a store return an error, or the type exposes only reads — least code). `TestStatusDoesNotWriteArchive`: mtime and size of `archive.db` (and no `-wal`/`-shm` created if absent before) unchanged after `status` and `chats`; `status --data <missing>` exits non-zero and creates nothing.
2. Health snapshot gains `version` and `version_reason` (the monitor already has `versionInUse`; add a reason func or pass both — least churn; `serve` wires `client.VersionInUse`/`VersionReason`). `status` prints them; missing health.json → prints `state: unknown (health.json not found)`.
3. Time zone: `cfg.TimeZone` via `time.LoadLocation`; empty → UTC; invalid → error from the command. All times printed as `2006-01-02 15:04 MST` in that zone; zero/unknown times print `-`.
4. History coverage line: `history: complete back to <date of oldest history message>` if any ledger chunk has progress 100, else `history: in progress (<last progress>%)`, plus `chunks <n>, last chunk <time>`; no chunks → `history: none received yet`.
5. Per chat columns (tab-separated, stable order by canonical JID): name, canonical JID, messages, oldest, newest, media failed, media expired, media pending, open gaps. Totals line sums the numeric columns. `recovered panics: <n>` from health.json. `data folder: <human size>` (walk `cfg.DataDir`, sum file sizes, format with one decimal and B/KB/MB/GB). Add store read queries only as needed (`ChatStats` may gain expired/pending counts — same query style, reads only).
6. `chats`: canonical JID, name, message count, `excluded=yes|no` where excluded if the canonical JID or any of its aliases (`store.Aliases`) is in `cfg.Exclude` (fixes L2's canonical-only match).
7. Golden files in `cmd/archiver/testdata/status.golden` and `chats.golden`, compared byte-for-byte; an `-update` flag in the test writes them.
