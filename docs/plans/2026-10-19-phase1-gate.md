## Review Focus

- A history notification redelivered after a restart, possibly more than once: exactly one ledger row, no duplicate raw rows, and the view shows each message once. Pinned by Task 2 `TestNoHistoryLossAcrossInjectedShutdown`.
- A history blob download that hangs (slow CDN or a half-open socket): the handler runs synchronously, so a hang would stall every live event. The download needs a bound, and a timeout means no ack. Pinned by Task 2 `TestHistoryDownloadIsBoundedAndNotAckedOnTimeout`.
- SIGTERM while a history download or import is in flight: the 30 s drain cuts it, the notification is not acked, and no ledger row is written. Pinned by Task 2 `TestInterruptedHistoryImportLeavesNoLedgerRow`.
- A connection that flaps many times a minute: one `connection lost` and one `connection restored` per transition, never per event. Pinned by Task 4 `TestConnectionLinesOnlyOnTransition`.
- Redaction that is too eager: an error that holds a JID, a file path or a plain host must keep it. Only a URL's query string and fragment are removed. Pinned by Task 4 `TestRedactURLsKeepsNonURLText`.
